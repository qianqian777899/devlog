# Changelog

## 0.1.0 — 2026-10-27

Initial open-source MVP.

- Offline daily, weekly and custom-range Markdown reports.
- Recursive Git discovery, worktree support and exact author filtering.
- Codex CLI and Claude Code JSONL adapters with event-level time and project scoping.
- Separate committed changes from AI requests and tool-referenced files.
- Chinese and English daily, weekly and OKR templates.
- Optional OpenAI-compatible AI polishing with pre-transmission redaction and offline fallback.
- Best-effort secret/path redaction, safe config initialization and guarded file output.
- Vitest fixtures, CLI integration tests, ESLint, TypeScript and GitHub Actions CI.
- Bilingual documentation, synthetic example reports and CLI demo.

The npm package is prepared but has not yet been published to the registry.
